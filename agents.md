# AGENTS.md

Руководство для AI-агентов, работающих в этом репозитории.

## О проекте

Статический сайт (GitHub Pages) — карты для скачивания приложением pMetro для Android.
Основной сайт проекта: http://pmetro.su

## Структура

```
Files.xml          — манифест всех карт (используется приложением pMetro)
Files.xsd          — XML-схема для валидации Files.xml
generate.py        — скрипт обновления дат в Files.xml по HTTP-заголовкам с pmetro.su
update_files_list.py — скрипт обновления Files.xml по фактическим файлам в download/
update.sh          — полный цикл обновления: скачивание pMetroSetup.exe, распаковка,
                    переупаковка .pmz в .zip, правка Files.xml
download/          — zip-архивы карт (1 zip на город, внутри лежит .pmz)
pmz/               — «сырые» файлы карт в формате .pmz
index.html         — главная страница
maps.html          — актуальный список карт (должен соответствовать Files.xml)
```

## Формат Files.xml

- Корневой тег `<FileList DataVersion="1" Date="...">`
- Для каждой карты: `<File>` → `<Zip Name Size Date>`, `<Pmz Name Size Date>`, `<City Name CityName Country>`, опционально `<Map Comment>`
- Атрибут `Date` — **Excel-serial date** (количество дней после 30.12.1899, с учётом «бага» високосного 29.02.1900). См. функцию `to_excel_date()` в скриптах.
- Кодирование файла: **windows-1251** (не менять!)
- Валидируется по `Files.xsd` перед любым переписыванием

## Ключевые правила работы с Files.xml

1. Не редактировать руками без проверки схемы.
2. Даты считать через `to_excel_date()`, не «в лоб».
3. Сохранять с кодировкой windows-1251 (в скриптах: `tree.write(..., encoding=encoding)`).
4. После обновления менять `Date` у корня `FileList`.
5. Файлы в `download/` — 1 zip = 1 город = 1 .pmz внутри.
6. `maps.html` содержит актуальный список карт и **должен соответствовать `Files.xml`**:
   при добавлении/удалении карт или изменении дат обновлять `maps.html` синхронно.

## Процесс обновления карт (см. README.md)

1. Обновить проект pMetro-maps, скопировать свежие карты в `download/`.
2. Выполнить `python update_files_list.py` — он сравнит реальные размеры/даты файлов с `Files.xml` и запишет `NewFiles.xml`.
3. Переименовать `NewFiles.xml` → `Files.xml`.
4. Проверить, что изменились только записи по обновлённым картам + тег `FileList` во второй строке.
5. Обновить `maps.html`, если список карт изменился (новый город, удаление, даты).
6. Закоммитить изменения в `download/`, `Files.xml` и, при необходимости, `maps.html`.

Альтернативный путь (через инсталлятор): `update.sh` — качает `pMetroSetup.exe`,
распаковывает через innoextract, переупаковывает `.pmz` → `.zip`, подправляет `Files.xml`
через sed. Для Moscow.zip использует версию с mrsuperwolf.github.io.

## Зависимости

- Python 3
- `lxml` (XML + валидация по XSD)
- Для `update.sh`: `7z` или `zip`, `innoextract`, `curl`

## Конвенции

- Язык коммитов и комментов — русский.
- Не менять структуру и кодировку `Files.xml` — от этого зависит работа приложения pMetro.
- `pmz/` — источник, `download/` — то, что скачивают пользователи.
